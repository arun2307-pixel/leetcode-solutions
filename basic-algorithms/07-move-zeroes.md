# Move Zeroes

**Difficulty:** Easy–Medium

**Link:** https://leetcode.com/problems/move-zeroes/

## Approach

Move all non-zero elements to the front while keeping their original order. After placing all non-zero elements, fill the remaining positions with zeroes.

## Complexity

**Time:** O(n)  
**Space:** O(1)

## Notes

The array is modified in-place without using another array.
